# Микропроект "Построение минимального описанного эллипсоида"

## Задача Сильвестра

Задача Сильвества заключается в построении минимальной описанной сферы. Она приводится к стандартной задаче квадратичного программирования с линейными ограничениями, поэтому имеет точное решение.

## Общая задача

Общая задача точного решения не имеет, однако существует ряд алгоритмов для поиска приближенного решения. Здесь реализован один из них -- алгоритм последовательных сжатий пространства.

### Сходимость алгоритма
